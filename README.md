# PiSim_Pi5 Platform

Raspberry Pi 5 Python bridge, dependencies, and native ROS 2 nodes for **PiSim (Unreal Engine 5)** simulation.

---

## ⚡ Quick Start on Raspberry Pi 5

Run the one-click automated setup script on your Pi 5:

```bash
chmod +x setup_pi5.sh
./setup_pi5.sh
```

---

## 🚀 Running Modes

### Mode 1: Standalone UDP Bridge (Non-blocking Teleop & FPV Stream)
Runs without requiring a ROS 2 installation on Pi 5:
```bash
python3 pisim_core.py
```
- **Control**: Real-time single-key WASD teleop sent to UE5 on UDP Port 7400.
- **Telemetry**: Listens for `/sim/imu` on UDP Port 7401.
- **FPV Video**: Live OpenCV camera stream on UDP Port 5000.

### Mode 2: Native ROS 2 Node (rclpy & ROS 2 Environment)
Integrates directly with native ROS 2 packages (`rclpy`, `rviz2`, `rqt_image_view`):
```bash
python3 pisim_ros2_node.py
```
- Publishes ROS 2 Topics:
  - `/sim/imu` (`sensor_msgs/msg/Imu`)
  - `/sim/camera/image_raw/compressed` (`sensor_msgs/msg/CompressedImage`)
- Subscribes to ROS 2 Topic:
  - `/cmd_vel` (`geometry_msgs/msg/Twist`)

---

## 📁 File Structure

- `setup_pi5.sh`: Automated dependency setup script for Pi 5.
- `requirements.txt`: Python package requirements (`opencv-python`, `numpy`, `pynput`).
- `pisim_core.py`: Standalone UDP bridge for teleoperation, IMU telemetry, and FPV video.
- `pisim_ros2_node.py`: Native ROS 2 node supporting `geometry_msgs` and `sensor_msgs`.
- `robot_config.json`: Virtual Port configuration generated by UE5 Garage.
