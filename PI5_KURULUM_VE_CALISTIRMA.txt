================================================================================
 PISIM - RASPBERRY PI 5 KURULUM VE ÇALIŞTIRMA KILAVUZU
================================================================================
Bu kılavuz, PiSim otonom araç sürüsü, ArduPilot L1 otopilot mimarisi ve
dağıtık Zenoh ağı bileşenlerinin kullanımını içerir.

--------------------------------------------------------------------------------
1. MİMARİ DOSYALARI
--------------------------------------------------------------------------------
1) mission_planner.py   : Parametrik rastgele görev ve 4 hedef üreteci (100m kuralı)
2) agent_supervisor.py  : Bağlantı kontrolcüsü, görev koordinatörü ve sabit HUD
3) autopilot_driver.py  : ArduPilot AP_L1_Control otopilot navigasyon motoru
4) vehicle_hardware.py  : Ackermann direksiyon ve aktüatör fizik katmanı
5) zenoh_mesh.py        : Zenoh router ve yönlendirici omurga
6) video_stream_tester.py: Video/kamera yayıncısı ve web izleyicisi

--------------------------------------------------------------------------------
2. PI 5 DOCKER KONTEYNERLERİNİ ÇALIŞTIRMA (Rover 04, 05, 06)
--------------------------------------------------------------------------------
1. Kodları güncelleyin:
   cd ~/PiSim_Pi5
   git pull origin main

2. Konteynerleri ayağa kaldırın (Windows Wi-Fi IP'niz ile):
   cd ~/PiSim_Pi5/docker
   docker compose -f docker-compose.pi5.yml down
   WINDOWS_IP=192.168.1.3 docker compose -f docker-compose.pi5.yml up -d --build

--------------------------------------------------------------------------------
3. SABİT (AŞAĞI KAYMAYAN) CANLI AJAN EKRANINI İZLEME
--------------------------------------------------------------------------------
Herhangi bir konteynerin otonom karar beynini ve canlı HUD gösterge panelini
izlemek için (Şelale gibi akmaz, sabit gösterge kutusu olarak güncellenir):

   # Rover 04'ü izlemek için:
   docker attach pisim_agent_rover_04
   # (Veya terminalden ayrılmak için Ctrl+P ardından Ctrl+Q tuşlayın)

   # Ya da doğrudan exec ile:
   docker exec -it pisim_agent_rover_06 python agent_supervisor.py --vehicle rover_06 --distance 100

--------------------------------------------------------------------------------
4. GÖREV PLANLAYICIYI BAĞIMSIZ TEST ETME (Dosya 1)
--------------------------------------------------------------------------------
Kendi parametrelerinizle 100m aralıklı 4 hedef üretmek için:
   python3 mission_planner.py --distance 100 --count 4 --save gorev.json

--------------------------------------------------------------------------------
5. CANLI VİDEO AKIŞINI TARAYICIDAN İZLEME
--------------------------------------------------------------------------------
İzole Rover 06 konteyneri içinde web yayıncısını başlatıp Firefox'tan izleyin:
   docker exec -it pisim_agent_rover_06 python video_stream_tester.py --view --web 8088
   Tarayıcıdan: http://localhost:8088 veya http://<PI5_IP>:8088
================================================================================
